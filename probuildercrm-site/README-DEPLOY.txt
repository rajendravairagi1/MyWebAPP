PRO BUILDER CRM — MARKETING WEBSITE
=====================================

WHAT'S IN THIS ZIP
-------------------
This is a plain, static website (no PHP, no database) — index.html,
features.html, pricing.html, faq.html, about.html, plus assets/,
robots.txt and sitemap.xml. It has nothing to do with the CRM app
itself (businessflow) — it's a separate sales website meant to run on
its own domain: ProBuilderCRM.com.

HOW TO UPLOAD (cPanel)
-------------------
1. In cPanel, go to "Domains" and add ProBuilderCRM.com as a new
   domain (or addon domain) pointing to its own folder, e.g.
   public_html/probuildercrm/
2. Open File Manager, go into that folder, and upload + extract this
   zip there.
3. Visit https://probuildercrm.com — it should load immediately, no
   install step needed (it's just static files).

BEFORE YOU GO LIVE — 3 THINGS TO EDIT
-------------------
1. WHATSAPP NUMBER — currently a placeholder. Open about.html and
   search for "91XXXXXXXXXX", replace it with your real WhatsApp
   number (with country code, no + or spaces, e.g. 919876543210).

2. EMAIL ADDRESS — currently set to hello@probuildercrm.com in
   about.html and the footer. Change it to whichever email you'll
   actually monitor (and make sure that mailbox exists once the
   domain's email is set up).

3. PRICING — the numbers on pricing.html (Solo ₹999, Team ₹2,499,
   Company ₹4,999 per month) are DRAFT numbers I picked as a
   reasonable starting point — not final. Tell me your real prices
   and I'll update the page in one go.

AFTER IT'S LIVE
-------------------
- Go to Google Search Console (search.google.com/search-console),
  add ProBuilderCRM.com, and submit sitemap.xml — this is what tells
  Google to start indexing the site for search (SEO).
- The FAQ page already has structured data (FAQ schema) built in —
  this is what helps the page show up in Google's "People also ask"
  and in AI answers (ChatGPT, Perplexity, Google AI Overview) when
  someone asks about real estate CRM software — no extra work needed
  there.
- Once you have a real logo, replace the "P" square logo mark
  (currently just text) across all 5 pages, and add a real
  og-cover.jpg image (1200x630px) to assets/images/ for how the site
  looks when shared on WhatsApp/social media.
